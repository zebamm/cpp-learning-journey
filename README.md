# C++ Learning Journey
Repositorio donde documento mi aprendizaje de C++. Desde ejercicios de gestión de memoria dinámica, hasta Programación Orientada a Objetos y arquitectura de sistemas.

El código está organizado de la siguiente manera según el concepto o paradigma aplicado:

* **`01_Control_de_Flujo/`**: Algoritmos básicos, bucles, validaciones y guard clauses.
* **`02_Memoria_Dinamica/`**: Punteros, el Heap, y gestión manual de recursos (`new` / `delete`).
* **`03_Estructuras_Datos/`**: Agrupación de datos complejos y arreglos dinámicos usando `struct`.
* **`04_POO_Basica/`**: Clases, encapsulamiento, abstracción y modelado de objetos.
* **`05_Listas_Enlazadas/`**: Implementación de nodos, manejo de enlaces simples y dobles, recorrido, inserción y eliminación dinámica de elementos.
* *(Módulos en expansión)*

## Tecnologías y Entorno
* **Lenguaje:** C++ 
* **Entorno / IDE:** Visual Studio (Compilador MSVC)
* **Enfoque:** Aplicaciones de consola robustas, manejo de búferes y código libre de fugas de memoria (memory leaks).

## Filosofía de Trabajo
Cada archivo y ejercicio de este repositorio representa un commit hacia la escritura de código limpio y modular. El enfoque principal está en aplicar buenas prácticas de la industria, como la validación estricta de entradas y el principio de responsabilidad única.
